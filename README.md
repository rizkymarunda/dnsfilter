# DNS Filter & IP Blacklist

A curated DNS blocklist and IP blacklist for use with Pi-hole, AdGuard, and other network filtering tools such as firewalls and router-based ad blockers.

This repository contains manually collected domain and IP entries from various sources to help block unwanted traffic, ads, tracking, malicious domains, and other known bad hosts.

## What this repository includes

- DNS blocklists for use with Pi-hole and similar tools
- IP blacklist entries for firewall and network filtering setups
- Easy-to-consume list files suitable for common filtering devices

## Supported use cases

- Pi-hole
- AdGuard Home
- DNS sinkholes
- Firewall rules
- MikroTik and other router/firewall environments
- Palo Alto and similar security appliances

## Typical usage

1. Download the desired list file from this repository.
2. Import it into your DNS filtering system or firewall.
3. Update your rules or blocklists regularly.
4. Review the list periodically to keep it relevant.

## Notes

This project is maintained as a simple, manually curated collection. It is intended for personal or small-network use and may need adjustment depending on your environment and filtering needs.

## Important

This is not a replacement for a full threat intelligence platform. Always validate blocklists against your specific use case and network requirements.
